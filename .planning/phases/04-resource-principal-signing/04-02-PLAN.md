Mitigation: Exact tests assert `keyId="ST$TEST_RPST"` and never the API-key
tenancy/user/fingerprint shape.

Mitigation: Exact tests assert `x-content-sha256`, `content-type`, and
`content-length` in both signing string and Authorization `headers`.
</threat_model>
