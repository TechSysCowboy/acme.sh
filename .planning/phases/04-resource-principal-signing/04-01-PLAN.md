<objective>
Add resource-principal material loading helpers and focused tests for the v2.2
environment contract.

Purpose: Give Phase 4 signing a safe request-local source of RPST, private PEM,
optional passphrase, and region material without persisting or normal-logging
secret values.
Output: Loader tests plus private helper(s) in `dnsapi/dns_oci.sh` that support
path-first inline fallback and clean diagnostics.
</objective>

<threat_model>
T-04-01: Loading RP material during auth selection could cache stale token/key
contents and break OCI rotation.
Mitigation: Keep `_oci_resource_principal_configured` as detection-only and call
material loading only from the RP signing helper.

T-04-02: Path or inline values could be persisted through existing account
config helpers.
Mitigation: Tests must assert no `OCI_RESOURCE_PRINCIPAL_` names or fixture
values appear in saved or cleared account config captures.

T-04-03: Normal diagnostics could leak secret paths or inline values.
Mitigation: Missing and load-failure messages must use env var names and
failure classes only.
</threat_model>
